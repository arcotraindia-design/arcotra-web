# Arcotra — web sitesi

ARCOTRA PRIVATE LIMITED tanıtım sitesi. Tek sayfa, çerçeve yok, derleme adımı yok.

    index.html    sayfanın tamamı (HTML + CSS + küçük bir JS)
    img/          logo ve fotoğraflar

## Yayın

GitHub Pages, `main` dalının kökünden yayınlanır. `main`'e her gönderim canlıya çıkar.

## Görselleri değiştirmek

`img/` içindeki dosyayı aynı adla değiştirmek yeterli — HTML'e dokunmaya gerek yok.
Fotoğraflar şu an **yer tutucu** (Unsplash, ticari kullanıma açık lisans). Gerçek proje
render'ları geldikçe değiştirilecek; hero'daki ve plan çizimindeki "placeholder"
notları da o zaman kaldırılacak.

## Bekleyenler

- Gerçek proje görselleri (`img/photo-*.jpg`)
- Müşteri yorumları — `#clients` bölümündeki üç kart bilerek boş bırakıldı
- Alan adı `arcotratrade.com` bağlanacak (DNS Squarespace'te; e-posta kayıtlarına dokunulmayacak)
